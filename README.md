# Sovereign Cash Co.

A premium concept site for a Native-owned, hospitality-led, software-powered ATM company.

## Run

```bash
npm install
npm run dev
npm test
npm run build
```

## Concept

The brand combines luxury hospitality with **SignalOS**, a proposed operations and venue intelligence layer. Differentiators include predictive cash demand, proactive maintenance, transparent economics, event surge planning, the Local Loop local-commerce network, Cash Concierge event service, custom hardware treatments, and community impact reporting.

This is a concept—not a claim that the company, certifications, product features, performance figures, testimonials, or service commitments currently exist. Validate the name, trademark, domain, economics, compliance obligations, processor relationships, insurance, hardware claims, and Native-owned certification language before launch.
